## Проверка именно окончательного ZIP на реальных данных

Запуски последовательные, в чистых папках, Python 3.12.14/macOS, два потока,
бюджет 300 с на запуск, локальный порог памяти 3 GiB. Qwen отключена, платных запросов нет.
В обоих случаях файл сформирован обученной моделью, а не только запасным простым ответом.

| Задача | Время всей программы | Строк в ответе | Лучшая метрика на собственной валидации | Пиковая суммарная RSS |
|---|---:|---:|---|---:|
| Энергопотребление зданий | 92.7 с | 22,449 | rmse = 43.207493 | 647 MiB |
| Типы сетевых атак | 90.1 с | 41,166 | macro_f1 = 0.579502 | 579 MiB |

Метрики относятся к внутренней валидации. Это не баллы платформы и не качество на скрытом тесте.
Измеренная RSS суммируется по процессам и может повторно учитывать общую память.

## Что еще требует внешней проверки

Docker отсутствует на этом компьютере. Не выполнены запуск в Linux-контейнере платформы,
полный трехчасовой прогон и подключение настоящей Qwen из этой сборки.
Окончательная проверка интерфейса и доступности API — первый запуск на платформе.
Правило о плоском ZIP взято из документации команды; исходная дополнительная инструкция
организаторов отдельно не предоставлена. Восстановление рабочих папок выполняется внутри
каталога задачи, где, согласно документации команды, разрешены промежуточные файлы.

Контроль памяти реализован мониторингом с остановкой при >28 GiB по умолчанию,
а не жесткой квотой ОС. Границу контейнера 32 GB обеспечивает платформа.
