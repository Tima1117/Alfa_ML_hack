# Повторная проверка CONTRACTS.md — 21 октября 2026

## Что уточнил присланный контракт

Платформа копирует только корневые `.py` и `requirements.txt`, вложенные файлы из ZIP
отбрасывает. Также подтверждено, что таймауты отдельных экспериментов уже есть
в `agent.executor.SubprocessExecutor`; инфраструктуре не нужно заново их реализовывать.

## Вывод для нашей сборки

Работающий ZIP уже соответствует правилу: в нем только `solution.py`,
`bundle_sources.py`, `requirements.txt`. Все исходники пакетов включены в корневой
Python-файл как обычные строки. Рабочие папки восстанавливаются после старта внутри
каталога задачи. Сохранены исходные имена пакетов, запуск `python -m agent._worker`
и путь к `_feature_sandbox_runner.py` рядом с модулем.

Предложенное в контракте переименование всех модулей — другой способ выполнить
то же правило. Из приведенного описания платформы не следует запрет создавать
рабочие папки после запуска. Поэтому менять уже работающие импорты не потребовалось.
Этот вывод проверен локальной имитацией загрузки; сама платформа еще не запускалась.

В присланном контракте есть сведения из другой версии ML-ядра: `feature_steps`
назван неработающим полем, а в используемом релизе agent-v1 уже есть реализация
`ml_core/feature_steps.py` и ее применение при обучении. Актуальный раздел сохранен;
новый файл целиком поверх рабочего контракта не копировался.

## Что изменено

- В `scripts/verify_submission.py` добавлен `--platform-copy`: копируются только
  разрешенные корневые файлы прямо к CSV, запуск идет из папки задачи командой
  `python solution.py task.md`, без репозитория в PYTHONPATH.
- Добавлен тест, который намеренно помещает вложенные `.py` и README в ZIP,
  затем отбрасывает их как платформа и проверяет запуск из оставшихся файлов.
- Добавлен отдельный тест запуска проверки кода признаков из восстановленного
  пакета: `_feature_sandbox_runner.py` найден и исполняется по правильному пути.
- Уточнены docs/CONTRACTS.md, docs/INFRASTRUCTURE.md и заметки передачи работы.
- **14 инфраструктурных тестов прошли**. Ранее пройдены 57 исходных тестов проекта;
  всего проверен 71 различный сценарий, не одним общим прогоном после этой правки.
