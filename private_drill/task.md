# Прогноз дефолта по кредитным заявкам

## Задача

Постройте модель бинарной классификации, которая по характеристикам заявителя и условиям кредита оценивает вероятность дефолта — `default`. Одна строка соответствует одной кредитной заявке. Целевая переменная `default` принимает значения `Yes` (дефолт произошёл) и `No` (дефолт не произошёл).

Классы сильно несбалансированы: `No` встречается значительно чаще, чем `Yes`.

## Данные

Пути указаны относительно каталога этого Markdown-файла:

- `train.csv` — 4000 строк с признаками и таргетом.
- `test.csv` — 1500 строк с признаками без таргета.
- `data_dictionary.csv` — описание всех полей.
- `sample_submission.csv` — шаблон ответа; значения в нём не являются правильными ответами.

CSV используют UTF-8, запятую как разделитель и точку как десятичный разделитель. Пустая ячейка означает пропуск.

## Что предсказать

Для каждого `id` из `test.csv` необходимо предсказать вероятность дефолта (`default = Yes`) в виде числа от 0 до 1.

**Метрика оценки — ROC-AUC.** Чем выше ROC-AUC, тем лучше результат. Дополнительно может учитываться Precision-Recall AUC для несбалансированных классов.

## Формат результата

Файл `submission.csv` в каталоге этого Markdown-файла: CSV в UTF-8, разделитель — запятая, без дополнительного индекса, ровно два столбца:

```csv
id,default
```

Для каждого `id` из `test.csv` требуется одно число — вероятность дефолта от 0 до 1. Пропуски и повторяющиеся `id` недопустимы. Порядок строк должен совпадать с `test.csv`.
