# Прогноз оттока клиентов подписки

## Задача

Постройте модель бинарной классификации, которая по характеристикам клиента оценивает вероятность оттока (`churned`). Одна строка соответствует одному клиенту. Целевая переменная `churned` принимает значения `Yes` (клиент ушёл) и `No` (клиент остался).

## Данные

Пути указаны относительно каталога этого Markdown-файла:

- `train.csv` — 3500 строк с признаками и таргетом.
- `test.csv` — 1500 строк с признаками без таргета.
- `data_dictionary.csv` — описание всех полей.
- `sample_submission.csv` — шаблон ответа; значения в нём не являются правильными ответами.

CSV используют UTF-8, запятую как разделитель и точку как десятичный разделитель. Пустая ячейка означает пропуск.

## Что предсказать

Для каждого `customer_id` из `test.csv` необходимо предсказать вероятность оттока (`churned = Yes`) в виде числа от 0 до 1.

**Метрика оценки — log loss (logarithmic loss).** Чем ниже log loss, тем лучше результат.

## Формат результата

Файл `submission.csv` в каталоге этого Markdown-файла: CSV в UTF-8, разделитель — запятая, без дополнительного индекса, ровно два столбца:

```csv
customer_id,churned
```

Для каждого `customer_id` из `test.csv` требуется одно число — вероятность оттока от 0 до 1. Пропуски и повторяющиеся `customer_id` недопустимы. Порядок строк должен совпадать с `test.csv`.
